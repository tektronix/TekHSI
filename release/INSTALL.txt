TekHSI EUCRA bundle (1.1.0)
===========================

Contents
--------
  tekhsi-1.1.0-py3-none-any.whl   TekHSI library (TLS, credential store, Basic auth)
  EUCRA_USAGE.md                  User guide for secure connections
  check_tekhsi_endpoint.py        Probe an instrument and verify you can connect

Requirements
------------
  Python 3.10 - 3.13

Install
-------
  python -m venv .venv
  .venv\Scripts\activate          (Windows)
  source .venv/bin/activate       (Linux/macOS)

  pip install tekhsi-1.1.0-py3-none-any.whl

  pip pulls in grpcio, cryptography, numpy, tm_data_types, and other
  dependencies automatically from the wheel metadata.

Check an instrument
-------------------
  python check_tekhsi_endpoint.py 169.254.6.254
  python check_tekhsi_endpoint.py 192.168.1.50 --port 5000

  Reports what the server requires (encryption and/or password) and whether
  this client can connect. If a password is required, you will be prompted
  unless you pass --password or set TEKHSI_PASSWORD.

Usage guide
-----------
  See EUCRA_USAGE.md for TekHSIConnect examples (plain, TLS, TOFU, credential store).
